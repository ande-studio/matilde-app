# Matilde

PWA para profesionales de postas médicas en Perú que orientan a niñas y adolescentes. Funciona sin conexión, sin cuentas y sin recoger datos de pacientes.

> Estado: **Etapa 0 en desarrollo**. Todo el contenido es **borrador sin revisar**. Ver la documentación de producto y arquitectura en el repositorio `matilde-knowledge-base`.
